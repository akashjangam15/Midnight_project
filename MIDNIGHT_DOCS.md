# Midnight Network — Documentation Reference

**Main docs:** https://docs.midnight.network/

Midnight is a privacy-first blockchain that blends public verifiability with
confidential data handling (zero-knowledge proofs). Smart contracts are written
in **Compact** (a strongly, statically typed, bounded language) and paired with
TypeScript apps via the Midnight SDK.

- Docs cover: Compact language reference, SDK for wallet/contract interaction,
  Midnight.js API references.
