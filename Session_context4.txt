## Current Issue Being Debugged
**Lace wallet connection failing with "Network ID mismatch (InvalidRequest)" error**

Even though:
- `.env` has `VITE_NETWORK_ID=preprod`
- Lace wallet is on Preprod network
- Connection still fails

## Investigation Findings
1. Initial error was "network id mismatched" — fixed by creating `.env` with `VITE_NETWORK_ID=preprod`
2. After fix, new error: "Remote API with channel 'feature-flags' was shutdown: object can no longer be used"
3. After refresh, error became: "Network ID mismatch (InvalidRequest)"
4. **Current hypothesis**: Case sensitivity issue — Lace may be sending "Preprod" (capital P) while dApp sends "preprod" (lowercase)
